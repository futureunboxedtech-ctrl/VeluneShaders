VELUNE is a cinematic Minecraft shader project designed to enhance the game's visuals with realistic lighting, atmospheric effects, reflective water and immersive environments.

Features
- Realistic lighting and shadows
- Volumetric lighting and god rays
- Reflective water and atmospheric effects
- Enhanced Nether environments
- Custom cosmic experience featuring Gargantua
- Procedural planetary visuals

Compatibility
- Minecraft Java Edition
- Iris Shaders
- Sodium

Development
This project was developed with substantial assistance from generative AI. Its source code is shared here for transparency and project development.
