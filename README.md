What's new and included in V5
Water — turquoise shallows transitioning into deep blue, seabed caustics, shoreline foam, light through wave crests, sun glitter, sky/cloud/star/moon reflections, screen-space reflections, refraction, and depth-based colour absorption. Underwater visibility is clear at close range and gradually fades with depth.
Caves — cool blue-teal ambient illumination keeps nearby cave surfaces readable while distant tunnels retain a dark, atmospheric fade. Held torches, lanterns, and other supported light sources illuminate nearby surroundings. Controls include Cave Brightness, Cave Darkness Fog, and Held Torch Light.
Gargantua — a procedural black hole in the End with a dark shadow, photon ring, and gravitationally lensed accretion disk, including relativistic Doppler beaming and gravitational redshift.
The End — a ringed planet with ring shadows and a procedural planetary system. The black hole can act as the End's sun, with related lighting and shadows.
Lighting and atmosphere — soft coloured shadows, volumetric god rays, procedural clouds, sunsets, night-sky details, Milky Way, shooting stars, and moon phases.
Additional effects — rain puddles, fireflies near firefly bushes, coloured light bleed, Nether atmosphere, bloom, ACES tonemapping, and FXAA.
Quality presets — Low, Medium, High, and Cinematic.

Installation
Install Minecraft: Java Edition and a compatible Iris Shaders + Sodium setup.
The V5 package documentation specifies Iris matching your Minecraft version (for Minecraft 26.2, Iris 1.11.4+26.2 or newer) and Sodium 0.9.x. Install Fabric API only when using Fabric.
In Video Settings, set Graphics API to OpenGL. Iris does not support Vulkan.
Download VeluneShaders_V_5.zip and move the ZIP into your `.minecraft/shaderpacks` folder. Do not extract it.
Remove older VELUNE ZIPs/folders from `shaderpacks` so you can identify the correct pack.
Open Video Settings → Shader Packs, select `VeluneShaders_V_5`, and apply it. Press R in the shader-pack menu to reload shaders when needed.
Compatibility note: the V5 package README describes the 26.x Minecraft generation and gives Iris 1.11.4+26.2 or newer with Sodium 0.9.x as the 26.2 setup. Use versions that match your Minecraft installation; compatibility can vary by Minecraft, Iris, Sodium, GPU, and graphics driver.
Performance
For better performance, lower Black Hole Quality, Shadow Resolution, or God Ray Quality, or select the Low/Medium preset.
